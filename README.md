# Персональный планировщик времени и задач

Buildless PWA (чистый JS, ES-модули) с детерминированным математическим планировщиком — без ИИ в ядре. Ввод задач на русском разбирается keyword-парсером. См. [SPEC-v2.md](SPEC-v2.md).

## Запуск

Нужен любой статический http-сервер (модули и service worker не работают через `file://`). Проще всего — Python:

```bash
# из папки проекта
python devserver.py            # http://127.0.0.1:8200  (с заголовком no-store — удобно при разработке)
# или штатный сервер:
python -m http.server 8000     # http://127.0.0.1:8000
```

Затем открыть адрес в браузере. На телефоне/десктопе можно «Установить приложение» (PWA, работает офлайн).

## Тесты ядра

Открыть в браузере `tests/test.html` (через тот же сервер) — крошечный harness прогонит все проверки и покажет PASS/FAIL. Сейчас: **21/21 зелёные**. Тесты покрывают парсер, свободные слоты, скоринг, баланс, сплиттинг, at-risk, детерминизм и сохранение ручных чанков.

## Структура

```
index.html            оболочка
manifest.webmanifest  PWA-манифест
sw.js                 service worker (network-first + офлайн-фолбэк)
icon.svg              иконка
css/styles.css        стили (тёмная тема, мобайл-первый)
js/
  app.js              контроллер SPA: главный экран (3 дня), ввод, экран подтверждения
  store.js            хранилище (localStorage)
  core/               ЯДРО (чистые функции, покрыто тестами)
    model.js          модель данных, константы, DEFAULT_CONFIG
    time.js           работа с датами/минутами (локальное время)
    dict.js           словари русского парсера
    parser.js         разбор текста -> черновик задачи + confidence
    recurrence.js     разворачивание повторяющихся событий
    freeSlots.js      расчёт свободных слотов (D.1)
    scoring.js        importance x urgency x balanceFactor (D.2)
    scheduler.js      жадное размещение, сплиттинг, at-risk (D.3-D.6)
tests/                тесты ядра (test.html + core.test.js + assert.js)
```

## Что уже работает (P0)

- Ввод задачи текстом на русском → авторазбор времени, длительности, повторяемости, дедлайна, важности, характера, категории.
- Экран подтверждения: красное — не распознано (обязательно заполнить), жёлтое — угадано (подтвердить).
- Детерминированный планировщик: ургентность по «слаку», защита стратегии (цель 33 %), сплиттинг длинных задач, флаг at-risk с причиной.
- Главный экран на 3 дня: цвет = стратегия/тактика, форма = привязано ко времени / расставлено алгоритмом; плашка-итог по дню; линия «сейчас».
- Офлайн (service worker) + сохранение в localStorage.

## Известные ограничения v1

- Разбор текста — только русский, best-effort (правила + словари). Сложные формулировки правятся на экране подтверждения.
- Хранилище — localStorage, отдельно на каждом устройстве (синхронизации нет — P2).
- Перетаскивание чанков и полноценные экраны «Категории» / «Свободное время» / «Настройки» — следующий шаг.
- Уведомления перед началом задачи — P1.
